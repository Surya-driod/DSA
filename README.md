# Divide and Conquer

This repo explores the Divide and Conquer paradigm — solving complex problems by breaking them into subproblems.

##  Core Idea

1. Divide the problem
2. Conquer each subproblem recursively
3. Combine the results

##  Algorithms Covered

- Merge Sort
- Quick Sort
- Binary Search
- Matrix Multiplication
- Closest Pair of Points

##  Benefits

- Reduced time complexity
- Efficient recursion-based solutions

##  Structure

Each folder contains:
- Problem explanation
- Step-by-step breakdown
- Code in C++ or Python

# Greedy Algorithms

This repo showcases problems that can be solved by making locally optimal choices with the hope of reaching a global optimum.

##  Greedy Strategy

At each step, pick the best immediate option — no backtracking.

##  Classic Problems

- Activity Selection
- Fractional Knapsack
- Huffman Coding
- Minimum Spanning Tree (Prim’s, Kruskal’s)
- Job Sequencing

##  When to Use

- Optimal substructure
- Greedy choice property

##  Contents

- Problem statements
- Greedy strategy explanation
- Code implementations

# Backtracking

This repo covers backtracking — a brute-force search approach with pruning to find feasible solutions to constraint problems.

##  Approach

- Try a possibility
- Recurse
- Backtrack if it doesn’t lead to a solution

- Sudoku Solver
